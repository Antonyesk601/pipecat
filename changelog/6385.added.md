- Added `PipecatToneTagger` to expressive conversation (alpha), a processor that writes the expression tags for an LLM's plain replies with Pipecat Tone's tagger model. Placed between the LLM and the TTS service, it labels each sentence with a delivery, slow spans for details, stressed words and sounds, from the call so far, how the user sounded and the expression policy's presets, and writes them in the names the TTS service performs. The model downloads from Hugging Face at start and runs on the CPU. Install it with `pipecat-ai[tone]`. See `examples/expressive-conversation/expressive-conversation-tone-tagger.py`.
